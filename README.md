# DuoLayoutDemo – SwiftUI

A small SwiftUI learning project exploring the new **iPhone Duo APIs introduced in iOS 27.1**.

I built this project while following a tutorial to get hands-on experience with adaptive layouts for foldable devices.

## What I Explored

- **Toolbars:** Adaptive toolbar item placement using `ToolbarItem` and `toolbarVerticalEdge`.
- **Fold Regions:** Detecting fold and camera areas with `reservedRegions`.
- **Hinge Tracking:** Responding to device hinge angle changes using `.onHingeChange`.
- **Adaptive Layouts:** Exploring `ArrangementView` with `.automatic`, `.split`, and `.overlay` styles.

## Tech Stack

- Swift 6
- SwiftUI
- Xcode 27.1
- iOS 27.1+
